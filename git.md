## Git Commands

Clone the repository:

```bash
git clone https://github.com/keshu9251/Credit-Card-Default-Prediction.git
cd Credit-Card-Default-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

Save and upload future changes:

```bash
git add .
git commit -m "Describe your changes"
git push origin main
```

The Streamlit Community Cloud deployment is connected to the GitHub repository. Updates pushed to the deployed branch can trigger a new deployment.
